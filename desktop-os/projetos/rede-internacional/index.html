Como funciona

Seis etapas, do login ao resumo impresso. Cada print é o sistema emulado lá embaixo — clique em ver ao vivo.

1Login e primeiro acesso

Entra com e-mail e senha.

Quem recebeu senha temporária precisa trocá-la antes de usar o sistema.

  • JWT
  • BCrypt
  • troca obrigatória
  • log de acesso

2Painel por perfil

Cada perfil vê um painel diferente.

Quem só consulta não vê o botão de criar ficha nem a administração.

  • ADMIN · EDITOR
  • SUPERUSER · USER
  • rotas protegidas

3Ficha do evento

Quatro etapas: dados, organização, custos e programação.

Na cidade-sede, a etapa de custos vira contrato e patrocínio.

  • validação por etapa
  • regra por cidade
  • total somado na hora

4Eventos e calendário

Toda ficha salva vira um evento.

Dá pra buscar na lista ou ver o mês inteiro no calendário.

  • FullCalendar
  • busca
  • próximos · concluídos

5Resumo para imprimir

Cada evento tem um resumo completo, pronto para imprimir.

O perfil USER recebe a versão sem valores, contrato e contatos.

  • CSS de impressão
  • resposta por perfil
  • quem criou · quem editou

6Usuários e acessos

O ADMIN cria contas, escolhe o perfil e entrega uma senha temporária.

Todo login, certo ou errado, fica registrado.

  • e-mail único
  • nome e sobrenome
  • IP e navegador
