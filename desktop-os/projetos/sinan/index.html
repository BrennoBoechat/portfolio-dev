Como funciona

Seis etapas, do login ao relatório. Cada print é o sistema emulado lá embaixo — clique em ver ao vivo.

1Login com Microsoft

Entra com a conta institucional. Só acessa quem foi liberado.

O perfil (ADMIN ou USER) vem do próprio login.

  • OAuth2 / OIDC
  • Entra ID
  • sessão HttpOnly
  • CSRF

2Dashboard

Quantas fichas existem, quantas entraram hoje e quantas faltam enviar.

O gráfico mostra o status do mês.

  • cache no Redis
  • números animados
  • gráfico mensal

3Ficha em etapas

O formulário vira um passo a passo curto, validado a cada etapa.

O CEP completa o endereço sozinho.

  • passo a passo
  • validação por etapa
  • autocomplete de CEP

4Modo offline

Caiu a internet? A ficha fica salva no aparelho, cifrada.

Quando a conexão volta, ela sobe sozinha, sem duplicar.

  • IndexedDB
  • AES-256-GCM no navegador
  • fila por usuário
  • Idempotency-Key

5Fichas, PDF e envio

Cada ficha ganha um número único, que nunca se repete.

Gera o PDF da ficha e marca quando ela foi enviada.

  • AAAAMM_NNNN
  • PDFBox
  • cache de PDF
  • exclusão lógica

6Relatório anonimizado

Exporta um CSV para análise, sem nenhum dado pessoal.

No banco, os dados pessoais ficam cifrados.

  • LGPD
  • sem dado pessoal
  • filtros por período e status
