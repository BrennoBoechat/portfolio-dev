# Portfólio — spikes (vaporwave + internet antiga)

Monorepo com **duas abordagens** do mesmo portfólio, pra comparar e escolher uma
antes de montar o projeto final (React + Vite).

> ⚠️ Ambos são **spikes** (protótipos descartáveis). Arquivo único, **100% offline**,
> sem nenhuma dependência de CDN. Conteúdo é genérico ("SEU NOME", etc.) — é só adaptar.

## Versões

| Pasta | Metáfora | Como navega |
|-------|----------|-------------|
| [`desktop-os/`](./desktop-os/index.html) | Um **sistema operacional** vaporwave dos anos 90 | Clica ícones → abre **janelas** arrastáveis. Pastas = projetos. Barra de tarefas + Iniciar. |
| [`scroll-journey/`](./scroll-journey/index.html) | Uma **estrada ao pôr do sol** | **Rola pra baixo**; o carro desce num trilho lateral, seções surgem com esculturas, colunas e artefatos. |

## Como abrir

Dê dois cliques no `index.html` de cada pasta (abre no navegador).

## Próximo passo

Escolher UMA das duas (ou um híbrido), aí sim montar o projeto React/Vite de verdade,
com componentes organizados, fontes retrô locais (pixel/Orbitron), acessibilidade e conteúdo real.
