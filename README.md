# Portfólio — spike (vaporwave + internet antiga)

Protótipo do portfólio, pra validar a ideia antes de montar o projeto final (React + Vite).

> ⚠️ É um **spike** (protótipo descartável). Arquivo único, **100% offline**,
> sem nenhuma dependência de CDN. Conteúdo é genérico ("SEU NOME", etc.) — é só adaptar.

## Versão

| Pasta | Metáfora | Como navega |
|-------|----------|-------------|
| [`desktop-os/`](./desktop-os/index.html) | Um **sistema operacional** vaporwave dos anos 90 | Clica ícones → abre **janelas** arrastáveis. Pastas = projetos. Barra de tarefas + Iniciar. |

## Como abrir

Dê dois cliques no `index.html` da pasta (abre no navegador).

## Próximo passo

Montar o projeto React/Vite de verdade, com componentes organizados, fontes retrô
locais (pixel/Orbitron), acessibilidade e conteúdo real.
